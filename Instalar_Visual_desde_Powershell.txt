Pasos para Instalar Python y Visual Studio Code para ejecutar .ipynb's


Abrir Powershell 

Instalar Python compatible con la librería de bitalino: 
winget install --id Python.Python.3.10 --version 3.10.11 -e

Instalar Visual Studio Code:
winget install --id Microsoft.VisualStudioCode -e

Instalar Extensiones de Python y Jupyter
code --install-extension ms-python.python
code --install-extension ms-toolsai.jupyter

Instalar Kernel
py -3.10 -m pip install --upgrade ipykernel

Registrar Python como Kernel
py -3.10 -m ipykernel install --user --name python310 --display-name "Python 3.10"


Si no funciona, desactivar Windows Defender y volver a intentar.
